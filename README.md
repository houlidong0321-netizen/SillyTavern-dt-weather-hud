# 剧情时间天气悬浮窗（SillyTavern 扩展）

一个 SillyTavern 第三方 UI 扩展：让 AI 每次回复时在正文末尾附带固定格式的
「日期 / 时间 / 天气」标记，扩展自动扫描并把最新信息显示在页面悬浮窗中。

## 运行原理

1. **注入提示词**：通过 `setExtensionPrompt` 向上下文注入系统指令，要求模型
   每次回复正文结束后另起一行，按固定格式输出：
   ```
   [日期: 2025-08-06 | 时间: 21:40 | 天气: 小雨转多云]
   ```
   注入内容会带上"当前已知的剧情时间"作为参考，让模型据此合理推进时间，
   而不是随意跳变。
2. **扫描识别**：监听消息渲染 / 编辑 / 删除 / 重新滑动(swipe) / 切换聊天等
   事件，用正则表达式从聊天记录**末尾往前**查找第一条命中固定格式的消息，
   提取日期、时间、天气三项信息。
3. **悬浮窗展示**：将提取结果实时显示在页面右上角的悬浮窗中，悬浮窗可拖动、
   可折叠、位置会被记忆。

## 额外特性

- ✅ **切聊天自动重扫**：每次切换到不同的聊天（`CHAT_CHANGED`），会重新
  从该聊天最后一条消息往前扫描，找到最近一条含固定格式的消息并显示。
- ✅ **设置入口位置**：后台配置面板通过标准的 `#extensions_settings2`
  容器接入，会出现在页面下方的 **扩展（魔法棒图标）** 按钮弹出的抽屉中，
  标题为「🕰️ 剧情时间天气悬浮窗」。
- ✅ **可选注入位置**：后台可选择
  - `聊天中（按深度插入）` IN_CHAT，可自定义深度
  - `提示词最前` BEFORE_PROMPT
  - `提示词固定位（兼容模式）` IN_PROMPT
  以及注入角色（System / User / Assistant）。
- ✅ **自定义 CSS**：后台提供文本框可导入自定义 CSS，实时覆盖悬浮窗样式；
  不启用时使用默认样式。
- ✅ **默认样式**：透明毛玻璃背景 + 圆角 + 阴影的现代化风格，不遮挡阅读。

## 安装方法

### 方式一：作为第三方扩展手动安装（推荐用于本地测试）

将本文件夹（包含 `manifest.json` / `index.js` / `style.css`）整体复制到
SillyTavern 安装目录下的：

```
public/scripts/extensions/third-party/dt-weather-hud/
```

然后重启 SillyTavern，或在「扩展」面板中点击刷新，即可在扩展列表里看到
「剧情时间天气悬浮窗」。

### 方式二：通过 Git 安装

如果将本文件夹发布为一个 Git 仓库，可以在 SillyTavern 的
「扩展 → 安装扩展」中粘贴仓库地址直接安装。

## 使用说明

1. 安装并启用扩展后，默认已经开启提示词注入，无需额外操作。
2. 打开任意角色卡开始聊天，AI 回复后，悬浮窗会自动显示最新的日期/时间/天气。
3. 点击底部工具栏的 **扩展（魔法棒）** 按钮，找到「🕰️ 剧情时间天气悬浮窗」
   展开设置：
   - 可以关闭注入（仅保留扫描显示功能）；
   - 可以切换注入位置 / 深度 / 角色；
   - 可以导入自定义 CSS 美化悬浮窗；
   - 可以手动点击「重新扫描当前聊天」强制刷新。
4. 悬浮窗标题栏可拖动改变位置，点击右侧箭头可折叠/展开。

## 视觉设计（v2：透明 HUD 风格）

默认样式已更新为 **完全透明背景的 HUD 组件**，参考 macOS 小组件 / 极简科技 HUD 风格：

- 无卡片、无实色背景、无蓝色调，仅保留文字、细线与微弱发光；
- 超大数字时间 `HH:MM` 居中，中间冒号每秒渐隐渐现闪烁一次；
- 时间下方两行：第一行「日期 / 星期」，第二行「天气图标 + 天气文字 + 温度」；
- 天气图标使用纯 SVG 线性图标（晴/云/雨/雪/雷/雾/夜），不使用任何 emoji；
- 左上角、右下角各有一个白色 L 型细线角框，页面加载后延迟渐显（fade-in + 发光）；
- 整个组件带有缓慢的呼吸感浮动动画；
- 悬浮窗可直接按住拖动（折叠按钮除外），折叠后仅保留时间行。

想单独预览这个设计效果，可以直接用浏览器打开本文件夹中的 **`demo.html`**——
它是一个完全独立的静态页面（不依赖 SillyTavern），用真实系统时钟每秒跳动来
演示同一套 CSS 效果，方便你在接入扩展前先确认视觉效果、调整字号 / 颜色。
真正在 SillyTavern 里运行时，`index.js` 用的是同一套结构和样式类名，只是
数据来源换成了"从剧情文本中扫描出的日期/时间/天气"。

如果想进一步自定义（字号、颜色、间距、角框大小、动画时长等），可以在
`style.css` 顶部的 `:root` 变量里统一调整，或者在后台设置的自定义 CSS 框里
覆盖任意选择器：`#dt_weather_hud_panel`、`.dt-hud-time-row / .dt-hud-hour /
.dt-hud-minute / .dt-hud-colon`、`.dt-hud-date-row`、`.dt-hud-weather-row`、
`.dt-hud-corner-tl / .dt-hud-corner-br` 等。

## 固定格式说明

扩展识别的固定格式（大小写、全半角冒号均兼容）：

```
[日期: YYYY-MM-DD | 时间: HH:MM | 天气: 描述文字]
```

如果你的角色卡 / 预设中已经有类似的时间戳系统，建议先关闭本扩展的
「启用提示词注入」，避免和已有系统冲突；仅保留扫描 + 显示功能同样可用，
只要模型输出的内容能匹配上述正则即可被识别。

## 注意事项

- 该固定格式依赖模型"听话"程度，如果模型经常不按格式输出，可以尝试
  切换到 `聊天中（按深度）` 注入位置并把深度设为 0（更靠近最新消息，
  权重更高），或者切换到更强的模型。
- 悬浮窗内容不会修改聊天记录本身，只是"读取显示"，可以放心开关。
